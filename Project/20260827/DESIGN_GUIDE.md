# BookMate 디자인 가이드

> DAY 29에서 정리한 화면 설계 기준입니다. 이후 페이지를 추가하거나 수정할 때 공통
> 기준으로 사용합니다.

## 1. 디자인 방향

- 책 표지와 콘텐츠가 돋보이는 따뜻한 화이트·그레이 기반의 화면
- 주요 행동은 바다색, 위험·오류·스포일러 안내는 핑크로 구분
- 한 화면에는 하나의 분명한 목적과 하나의 강한 기본 버튼 배치
- 카드가 반복되는 책 영역과 세로 목록 중심의 커뮤니티 영역을 시각적으로 구분
- 색상만으로 상태를 전달하지 않고 텍스트·아이콘·배지를 함께 사용

권장 색상 비율은 화이트·그레이 75%, 텍스트 15%, 바다색 8%, 핑크 2%다.

## 3. 타이포그래피

기본 글꼴은 `Pretendard`, 대체 글꼴은 `Noto Sans KR`과 시스템 산세리프를 사용한다.

| 구분 | 권장 크기 |
| --- | --- |
| 메인 제목 | 40~48px |
| 화면 제목 | 28~32px |
| 섹션 제목 | 24~28px |
| 카드 제목 | 17~20px |
| 본문 | 15~16px |
| 메타 정보 | 13~14px |
| 배지 | 12~13px |

제목은 굵기와 크기로 위계를 만들고, 본문은 충분한 행간과 대비를 유지한다. 모든 제목을
큰 글씨로 처리하지 않고 페이지 제목·섹션 제목·카드 제목을 구분한다.

## 4. 레이아웃과 간격

- 최대 콘텐츠 폭: 1,200px
- 데스크톱 좌우 여백: 48~80px
- 큰 섹션 간격: 80~120px
- 카드 내부 여백: 20~24px
- 기본 간격 단위: 8·16·24·32px
- 버튼·입력창 모서리: 8px
- 카드 모서리: 12~16px
- 배지는 알약 형태로 표시
- 그림자는 카드가 배경에서 구분될 정도로만 약하게 사용

## 5. 공통 컴포넌트

### 헤더

- 왼쪽: 로고, 책, 랭킹, 책 취향, 커뮤니티
- 오른쪽: 통합 검색, 로그인 또는 프로필
- 현재 메뉴에는 밑줄이나 바다색 표시를 함께 사용
- 데스크톱에서는 상단 고정, 모바일에서는 메뉴를 축약

### 버튼

- `Primary`: 바다색 배경, 화면의 핵심 행동 하나에 사용
- `Secondary`: 흰색 또는 투명 배경과 테두리
- `Text`: 보조 이동과 덜 중요한 행동
- `Danger`: 핑크색, 삭제나 위험 작업에만 사용
- `Disabled`: 회색과 낮은 대비, 클릭할 수 없음을 명확히 표시

버튼 문구는 “확인”보다 “책 검색”, “게시글 등록”처럼 결과가 드러나게 작성한다.

### 입력창과 검색

- 레이블은 입력창 위에 두고 placeholder만으로 의미를 전달하지 않는다.
- 포커스 시 테두리와 포커스 링을 함께 표시한다.
- 오류는 입력창 아래에 원인과 해결 방법을 짧게 표시한다.
- 통합 검색은 제목과 작가를 모두 찾을 수 있음을 안내한다.

### 책 카드

- 표지 → 장르 배지 → 제목 → 저자 → 평점 순서로 읽히게 구성
- 설명은 목록에서 짧게 제한하고 상세 화면에서 전체 제공
- 즐겨찾기는 일관된 위치에 배치하고 선택 상태에 텍스트 설명 제공
- 카드 전체를 클릭할 수 있어도 내부 버튼의 포커스와 동작은 분리

### 커뮤니티 목록

- 순위·카테고리·제목·연결된 책·작성자·작성일을 기본 정보로 사용
- 조회수·댓글·좋아요는 보조 정보로 정리
- 스포일러 글에는 색상과 “스포일러” 텍스트 배지를 함께 표시
- 책 카드와 구분되도록 세로형 목록 또는 에디토리얼 카드 사용

## 6. 주요 화면 구조

### 메인

1. 서비스 소개와 통합 검색
2. 인기 책과 책 상세 이동
3. 티어리스트·이상형 월드컵 등 책 취향 콘텐츠
4. 인기 게시글과 커뮤니티 이동
5. 서비스·정책·팀 정보 푸터

### 책 목록

검색, 장르·평점 필터와 정렬을 먼저 제공한 뒤 책 카드를 배치한다. 모바일에서는 필터를
버튼이나 접이식 패널로 전환한다.

### 랭킹

실시간·주간·월간 기간 탭과 장르 필터를 분리한다. 순위는 숫자만 크게 보이게 하기보다
책 제목·저자·평점과 함께 읽을 수 있게 구성한다.

### 책 취향

티어리스트와 이상형 월드컵을 하나의 취향 탐색 영역으로 묶고, 인기 결과를 본 뒤 직접
참여할 수 있는 흐름을 제공한다.

### 커뮤니티와 글쓰기

커뮤니티는 인기 주제·오늘의 질문·게시글 목록으로 시작한다. 글쓰기에서는 카테고리,
제목, 내용, 스포일러 여부를 확인한 뒤 등록하며 임시 저장과 취소 행동을 구분한다.

## 7. 반응형·접근성 점검

- 모바일에서는 강한 스크롤 스냅을 해제하거나 약하게 적용한다.
- 콘텐츠가 화면보다 길면 스냅을 강제하지 않는다.
- 키보드로 모든 링크·버튼·입력 요소에 이동할 수 있게 한다.
- `prefers-reduced-motion` 환경에서는 부드러운 이동과 큰 애니메이션을 끈다.
- 본문과 배경의 명도 대비를 확인한다.
- 호버뿐 아니라 포커스·선택·비활성 상태를 모두 설계한다.
- 이미지에는 대체 텍스트를 제공하고 아이콘 버튼에는 이름을 지정한다.
