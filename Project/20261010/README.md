# DAY 62 — 반응형 프론트 개편과 CBTfy 시연 영상 제작

> 2026-10-10 · 미니프로젝트 II, React, Responsive Web, UI/UX, Video Editing

오늘은 CBTfy 프론트의 사용성과 화면 대응 범위를 전반적으로 보완했다. 먼저
[PR #51](https://github.com/ybc9786/kosa_project/pull/51)에서 문제 풀이 흐름을 개선하고,
[PR #53](https://github.com/ybc9786/kosa_project/pull/53)에서 태블릿·모바일·큰 데스크톱에
맞는 반응형 레이아웃과 홈 화면 모션을 적용했다. 두 PR 모두 `develop`에 병합되었다.

기능 작업을 마친 뒤에는 비회원부터 회원·관리자까지 주요 이용 흐름을 녹화하고, 내레이션과
자막을 더해 CBTfy 시연 영상을 완성했다.

## 문제 풀이 사용성 개선

필기 문제의 보기를 마우스나 터치로 고르면 0.35초 뒤 다음 문제로 이동하도록 만들었다.
답안을 저장할 시간을 확보하면서도 문제를 계속 풀 때 반복해서 다음 버튼을 누르지 않도록 한
개선이다.

- 시험 모드와 학습 모드의 객관식 문제에 같은 자동 이동 규칙 적용
- 실기 주관식, 마지막 문제와 키보드로 선택한 경우에는 자동 이동하지 않음
- 대기 중 사용자가 직접 이동하거나 제출 창을 열면 예약된 이동 취소
- 이동할 때 가장 최근에 선택한 답안 상태가 저장되도록 처리
- 문제 이동 창의 기본 과목을 `전체 과목`으로 통일
- 진행 중인 응시가 여러 개면 가장 최근에 시작한 시험 하나만 상단 배너에 표시

## 화면 크기별 반응형 레이아웃

화면 너비 기준을 한곳에 정리하고 공통 헤더부터 학습·문제 풀이·결과 화면까지 반응형 규칙을
통일했다.

| 화면 구간 | 기준 | 적용한 구성 |
| --- | --- | --- |
| 큰 데스크톱 | 1920px·2560px 이상 | 본문 최대 폭 확대, 헤더와 본문 정렬, 카드 열과 문제 글자 크기 확대 |
| 데스크톱 | 1024px 이상 | 기존 데스크톱 구조 유지 |
| 태블릿 | 768~1023px | 햄버거 서랍 메뉴, 학습 LNB 통합, 학습 회차 카드 2열 |
| 모바일 | 767px 이하 | 여백 축소, 카드·표 1열 배치, 문제 풀이 상·하단 고정 바 |

### 공통 내비게이션

- `MobileDrawer`를 추가해 좁은 화면에서 공통 메뉴를 서랍으로 제공
- `LearningNavContext`로 학습 화면의 LNB 메뉴를 모바일 서랍과 공유
- 고정된 헤더 높이를 CSS 변수로 관리해 화면별 높이 계산을 일관되게 처리

### 학습과 문제 풀이 화면

- 학습 홈의 회차 표를 태블릿에서는 2열, 모바일에서는 1열 카드로 전환
- 문제 풀이 화면에 상단 문제 정보와 하단 이전·다음·제출 버튼을 고정
- 문제 이동 버튼을 누르면 문제 이동 패널로 바로 이동하도록 연결
- 결과·복습·분석·오답노트·내 학습·로그인 화면의 좁은 화면 배치 정리
- 1920px 이상에서는 학습 메뉴와 본문을 함께 가운데 정렬하고 문제 글자 크기를 확대

## 홈 카드 모션과 시각 효과

- 자격증 카드를 겹쳐 놓고 이전·다음 버튼, 방향키와 스와이프로 넘기는 `CertificationFan` 구현
- 선택한 카드는 크게, 양옆 카드는 단계적으로 작게 보여 현재 위치를 구분
- 마우스를 올리면 카드가 떠오르고 양옆 카드가 벌어지는 동작 추가
- 검색창·자격증 카드·내 학습 분류 버튼에 라이트·다크 모드별 브랜드 빛 번짐 적용
- 아직 제공하지 않는 예시 자격증은 `준비 중` 상태로 비활성화

## CBTfy 시연 영상 제작

서비스의 주요 기능을 실제 이용 순서에 맞춰 녹화한 뒤 Premiere에서 하나의 시연 영상으로
편집했다.

- 비회원 시험 응시와 결과 확인
- 회원가입·로그인, 마이페이지와 Google 계정 연결
- 회원의 필기시험, 학습 모드와 라이트·다크 모드 전환
- 관리자 화면과 반응형 화면 변화
- 기능별 녹화본 정렬, 불필요한 구간 제거와 민감 영역 마스킹
- 내레이션 속도와 문장 끝을 다듬고 자막 타이밍을 맞춰 최종본 출력

[YouTube에서 CBTfy 시연 영상 보기](https://youtu.be/3XmpnHquBQA)

영상은 일부 공개 링크로 공유했으며, 포트폴리오 저장소에는 원본 영상이나 편집 프로젝트를
복사하지 않았다.

## 공개 전 보안 점검

- `cbtfy_vedio` 폴더에는 정지 이미지가 없어 일지에 첨부한 이미지가 없다.
- MOV·MP4 영상, WAV 음성, SRT·JSON 자막, 대본과 Premiere 프로젝트·자동 저장 파일을 모두 제외했다.
- 로그인·마이페이지·Google 연동·관리자 화면이 들어 있는 원본 녹화 파일은 저장소에 올리지 않았다.
- Premiere 프로젝트에 포함될 수 있는 로컬 경로와 원본 파일 연결 정보도 공개하지 않았다.
- 두 PR의 추가 내용에서 API 키·OAuth 비밀값·토큰·개인키·DB 비밀번호 형식을 점검했으며 발견되지 않았다.
- 일부 공개 YouTube 영상은 링크를 아는 사용자가 볼 수 있으므로 저장소에는 링크만 남겼다.
- 팀 프로젝트 저장소는 읽기 전용으로 확인했으며 이번 일지 작업으로 수정하지 않았다.

## 오늘의 정리

- 객관식 답안 선택 후 자동 이동과 최근 진행 시험 배너로 문제 풀이 흐름을 간결하게 만들었다.
- 390px 모바일부터 2560px 큰 데스크톱까지 대응하는 반응형 기준을 통일했다.
- 모바일 서랍 메뉴와 학습 메뉴 공유 구조를 만들고 주요 화면을 화면 폭에 맞게 재배치했다.
- 자격증 카드 모션과 브랜드 빛 번짐으로 홈 화면의 시각적 완성도를 높였다.
- 기능 녹화, 내레이션·자막 편집과 마스킹을 거쳐 CBTfy 시연 영상을 완성했다.
