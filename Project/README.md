## 폴더 구성

```text
Project/
├── README.md
└── YYYYMMDD/
    ├── README.md
    └── images/
```

새로운 프로젝트 기록은 `YYYYMMDD` 형식의 날짜 폴더를 만들고, 그 안에 작업 요약과
공개 가능한 결과 이미지를 넣어 관리합니다. 팀원의 개인정보, 비밀번호, 접속 정보와
환경 설정 파일은 공개 저장소에 올리지 않습니다.
