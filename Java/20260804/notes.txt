객체지향 프로그램
객체는 의사나 행위가 미치는 대상, 구체적, 추상적 데이커 단위
OOP object originated program 
객체를 정의하고, 객체의 기능 구현, 객체 사이의 협력 구현하는 일련의 과정이 객체지향을 말한다. 

객체 지향은 클래스를 기반으로 하는 프로그램밍이라,
클래스는 객테에 대한 속성과 기능을 구현한 것, 객체의 속성은 객체의 특성, 속성, 멤버 변수 
property, attibute, member varuable, 
객체가 하는 기능들을 메서드로 구현한다. method, member function

속성을 멤버 변수
기능은 메서드

..

클래스는 대부분 대문자로, 하나의 자바 파일에 하나의 클래스를 두는 것이 원칙이나 여러개의 클래스가 있을 수 있지만 public클래스는 하나 존재해야한다. 
+모든 함수는 Main이 먼저 돌아간다.
..

패키지는 클래스 파일의 묶음, 패키지를 만들면 프로젝트 하위에 물리적인 디렉토릴르 가지고,
course, student와 같이 기본이 되는 클래스를 기반으로 하위 클래스를 구성한다.
소스의 묶음 카테고리, 계층 구조로 구성되며 소문자로 명명
프로젝트 전체의 소스 코드를 구성하는 계층구조이고, 이 계층구조의 소스코드를 잘 관리하고 유지, 보수 해야함. 

..

스택는 함수가 호출될때 사용하는 메모리로, 기능 수행이 끝나면 반환되는 메모리이다.
c는 해제를 직접해줘야하지만 자바는 자동 반환

package chap05.classpart;

public class FuctionTest {
    public static void main(String[] args) {

        //매서드
        //함수를 구련하고 호출하는 부분을 구현해 보자
        int num1 = 10;
        int num2 = 20;

        int sum = add(num1, num2);// addnum의 값을 찾기 위해 addnum을 지정한 곳으로 들어감.
        System.out.println(sum);
        int sum1 = minus(num1, num2);
        System.out.println(sum1);
        int mult = multiply(num1, num2);
        System.out.println(mult);
    }

    public static int add(int n1, int n2) { // 내가 만든 함수
        int result = n1 + n2;
        return result; // 호출하지 않으면 사용되지 않는다. 없는 경우에는 void
    }

    public static int minus(int n1, int n2) {
        int result = n1 - n2;
        return result;
    }

    public static int multiply(int n1, int n2) {
        int result = n1 * n2;
        return  result;
    }
}
