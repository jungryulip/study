
## 새 일지 추가 방법

1. 알맞은 분야 폴더에 `YYYYMMDD` 형식의 날짜 폴더를 만듭니다.
2. 날짜 폴더의 `README.md`에 배운 내용과 실습 결과를 정리합니다.
3. `app/study-data.ts`의 `posts` 배열 맨 위에 새 기록을 추가합니다.
4. 이 README의 전체 학습 일지 표 맨 위에 날짜·일차·주제를 추가합니다.

`main` 브랜치에 변경 사항을 올리면 GitHub Actions가 포트폴리오를 자동으로 다시 배포합니다.
