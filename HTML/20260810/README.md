## 웹과 HTML

웹은 인터넷을 통해 문서와 서비스를 주고받는 환경입니다. 클라이언트가 정보를
요청하면 서버가 결과를 응답하며, 브라우저에 보이는 화면은 프론트엔드가, 서버의
데이터 처리와 저장은 백엔드가 담당합니다.

HTML(HyperText Markup Language)은 웹 문서의 뼈대를 만드는 마크업 언어입니다.
CSS는 문서의 모양을 꾸미고 JavaScript는 사용자 동작에 반응하도록 만듭니다.

## 웹의 기본 동작

- IP 주소는 인터넷에 연결된 컴퓨터를 구별하는 주소입니다.
- 도메인은 숫자로 된 IP 주소를 사람이 기억하기 쉬운 이름으로 표현합니다.
- DNS는 도메인 이름에 해당하는 IP 주소를 찾아줍니다.
- HTTP는 웹에서 데이터를 주고받는 규칙이며 HTTPS는 통신을 암호화합니다.

웹 페이지를 만들 때는 시각·청각·운동·인지 능력이 다른 사용자도 정보를 이용할 수
있도록 웹 접근성을 함께 고려해야 합니다.

## HTML 문서 구조

```html
<!DOCTYPE html>
<html lang="ko">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>상품 소개 페이지</title>
  </head>
  <body>
    <h1>레드향</h1>
    <p>웹 페이지에 표시할 내용입니다.</p>
  </body>
</html>
```

`head`에는 문자 인코딩, 화면 크기, 문서 제목처럼 문서에 필요한 정보를 넣고,
`body`에는 브라우저 화면에 실제로 표시할 내용을 작성합니다.

## 텍스트와 목록

- `h1`~`h6`: 단계별 제목
- `p`: 문단
- `br`: 줄바꿈
- `hr`: 주제 전환을 나타내는 가로선
- `strong`, `em`: 의미가 있는 강조
- `b`, `i`: 시각적인 굵기와 기울임
- `ol`, `ul`, `li`: 순서 있는 목록과 순서 없는 목록
- `dl`, `dt`, `dd`: 용어와 설명으로 구성된 설명 목록

```html
<h2>레드향 샐러드 레시피</h2>
<ol>
  <li>레드향을 한입 크기로 자릅니다.</li>
  <li>채소를 씻어 물기를 제거합니다.</li>
</ol>
```

## 표 만들기

표는 `table` 안에 행을 뜻하는 `tr`과 제목 셀 `th`, 데이터 셀 `td`를 배치합니다.
`caption`으로 표의 제목을 제공하고 `thead`와 `tbody`로 구조를 구분할 수 있습니다.

```html
<table>
  <caption>상품 구성</caption>
  <thead>
    <tr><th>용도</th><th>중량</th><th>가격</th></tr>
  </thead>
  <tbody>
    <tr><td>선물용</td><td>3kg</td><td>35,000원</td></tr>
  </tbody>
</table>
```

`rowspan`은 여러 행의 셀을 세로로 합치고 `colspan`은 여러 열을 가로로 합칩니다.
`colgroup`과 `col`을 이용하면 열 단위 스타일도 지정할 수 있습니다.

## 이미지와 대체 텍스트

```html
<figure>
  <img src="images/spring.png" alt="제주의 봄 풍경">
  <figcaption>가장 먼저 봄을 맞이하는 제주도</figcaption>
</figure>
```

`src`에는 이미지 경로를 지정하고 `alt`에는 이미지가 보이지 않거나 화면 낭독기를
사용할 때 전달할 대체 설명을 작성합니다. 이미지 크기는 `width`와 `height`로 지정할
수 있지만 비율이 깨지지 않도록 한쪽 크기만 지정하는 방법도 사용할 수 있습니다.

## 실습 중 알게 된 점

- HTML은 디자인보다 먼저 문서의 의미와 구조를 표현합니다.
- 제목 단계와 목록, 표의 구조를 올바르게 사용하면 읽기 쉽고 접근 가능한 문서가 됩니다.
- 이미지의 상대 경로는 현재 HTML 파일의 위치를 기준으로 계산합니다.
- `alt`는 단순한 파일명이 아니라 이미지가 전달하는 정보를 설명해야 합니다.
- 표를 꾸미는 역할은 CSS가 담당하고 HTML은 표의 의미 있는 구조를 만듭니다.

## 오늘의 한 줄

HTML은 화면에 글자를 놓는 기술이 아니라 웹 문서의 의미와 구조를 설명하는 언어다.
