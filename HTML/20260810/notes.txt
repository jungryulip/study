- 여러 형태의 웹

인터넷의 다양한 서비스를 사용할 수 있는 출발점으로, 
디지털 트렌스폼, 오프라인의 모든 정보와 서비스를 온라인으로 옮기는 작업,
Html,css, javascript

-네트워크 이해

인터넷은 네트워크의 네트워크, 라우팅(중간 중계점)
클라이언트-정보를 보여달라고 작업을 처리해달라고 요청하는 쪽- 와 서버-정보를 보내주거나 처리하는 쪽-
프론트엔드는-웹브라우저 화면에 보이는 것을 개발, 백엔드-보이지 않는 서버를 개발

[요즘은 풀스팩으로 원함]

-웹기본 동작

IP주소와 도메인, DNS서버-domain name server-
인터넷에 연결된 수많은 컴퓨터를 구별하기 위한 주소, 4자리에서 6자리로 구성됨. 
숫자대신 영문으로 된 주소를 사용하면 서버에서 자동으로 IP주소로 변환해서 사용한다.
HTTP, HTTPS[암호화가 추가된 것]

-웹 접근성

고려사항- 접근성, 시각장애, 이동장애, 청각장애, 인지장애 고려해야한다. 
(참고사이트: 무인정보단말기 UI 플랫폼, 널리, AOA11Y)
