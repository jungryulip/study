# DAY 24 — JavaScript 제어문, 함수와 이벤트

> 2026-08-20 학습 기록

JavaScript의 연산자와 조건문·반복문으로 실행 흐름을 제어했다. `var`, `let`,
`const`의 차이와 스코프를 비교하고, 매개변수·반환값·익명 함수·화살표 함수를
작성했다. 마지막으로 이벤트 처리와 JavaScript 객체의 개념을 실습했다.

## 오늘 배운 내용

### 1. 연산자와 비교

- 산술·비교·논리 연산자 사용
- `==`는 형 변환 후 값을 비교하고 `===`는 값과 자료형을 함께 비교
- `||`, `&&`, `!`로 여러 조건을 결합하거나 반전
- 삼항 연산자로 간단한 조건식을 표현

### 2. 조건문

- `if`, `if-else`, `else if`로 조건에 따라 실행 경로 분기
- 중첩 조건문으로 여러 단계의 조건 처리
- `switch-case`로 정해진 값에 따른 메뉴와 세션 선택 구현
- `prompt()`, `alert()`, `parseInt()`를 이용한 사용자 입력 처리

```javascript
const price = Number(prompt("구매 금액을 입력하세요."));

if (price >= 100000) {
  alert("VIP 회원");
} else if (price >= 50000) {
  alert("GOLD 회원");
} else {
  alert("일반 회원");
}
```

### 3. 반복문

- `for`로 합계와 구구단 출력
- 중첩 `for`로 행과 열 형태의 반복 처리
- `while`과 `do-while`의 조건 검사 시점 비교
- `break`로 반복을 종료하고 `continue`로 현재 반복 건너뛰기

### 4. 변수와 스코프

- `var`는 함수 스코프이며 재선언·재할당 가능
- `let`은 블록 스코프이며 재할당만 가능
- `const`는 블록 스코프이며 선언과 동시에 초기화
- 지역 변수와 전역 변수의 접근 범위 비교
- `var` 호이스팅에서 발생할 수 있는 예상 밖의 결과 확인
- 전역 변수 사용을 최소화하고 기본적으로 `const`, 필요하면 `let` 사용

### 5. 함수

- 함수 선언과 호출
- 매개변수·인수·`return`을 이용한 값 전달
- 기본 매개변수로 생략된 인수 처리
- 익명 함수를 변수에 할당
- 즉시 실행 함수 표현식(IIFE)
- 화살표 함수로 간결하게 함수 작성

```javascript
const discount = (price, amount) => price - amount;
console.log(`할인된 가격: ${discount(30000, 5000)}원`);
```

### 6. 이벤트와 DOM

- 이벤트는 클릭처럼 브라우저에서 발생하는 사용자 동작
- 이벤트 핸들러는 이벤트가 발생했을 때 실행되는 함수
- `onclick`으로 HTML 요소와 함수 연결
- `document.querySelector()`로 요소를 선택해 배경색 변경

### 7. JavaScript 객체

- 프로그램에서 다루는 데이터와 기능의 기본 단위
- DOM 객체, 브라우저 객체, JavaScript 내장 객체
- 필요에 따라 직접 만드는 사용자 정의 객체

## 회고

조건문과 반복문은 실행 흐름을 만들고 함수는 그 로직을 재사용 가능한 단위로
분리한다. 특히 `var`의 함수 스코프와 호이스팅보다 `let`·`const`의 블록 스코프가
코드의 범위와 변경 가능성을 더 분명하게 표현한다는 점을 확인했다.
