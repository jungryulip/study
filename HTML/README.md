## 폴더 구성

```text
HTML/
├── README.md
└── YYYYMMDD/
    ├── README.md
    ├── notes.txt
    ├── example.html
    └── images/
```

새 학습 기록은 `YYYYMMDD` 날짜 폴더에 요약 문서와 원본 예제, 필요한 이미지를
함께 넣어 관리합니다.
